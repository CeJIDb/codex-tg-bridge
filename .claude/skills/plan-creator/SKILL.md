# plan-creator

Создаёт `plans/YYYY-MM-DD-*.md` строго по формату из `plans/README.md`.

## Алгоритм

1. **Определи дату** — сегодняшняя (`currentDate` из системного контекста или `date +%Y-%m-%d`).
2. **Определи slug** — из названия задачи: kebab-case, только латиница/цифры, без двойных/хвостовых
   дефисов.
3. **Проверь** — нет ли уже плана по той же задаче в `plans/` (если есть — работай с ним, не
   создавай новый).
4. **Создай файл** по шаблону ниже.
5. **Запусти валидатор**: `node ./scripts/plans/validate-plans.mjs plans/<имя-файла>.md`

## Шаблон

```markdown
# План: <Короткое название>

**Дата**: YYYY-MM-DD **Задача**: <одно предложение — что делаем>

## Зачем именно так

<контекст: почему такой scope, какие альтернативы отброшены>

## Цель

<конкретный проверяемый результат>

## Scope

**Входит:**

- <...>

**Не входит:**

- <...>

## Определение «готово»

- [ ] <критерий приёмки 1>
- [ ] <критерий приёмки 2>

## Фазы и статус

- [ ] Фаза 0. <подготовка>
- [ ] Фаза 1. <реализация>
- [ ] Фаза 2. <проверка>

## Итог

<заполняется по ходу и в конце сессии>
```

## Правила (из plans/README.md)

- Один план = одно изменение. Не смешивай задачи.
- Фазы обязательны (`[ ]` / `[x]`).
- `## Итог` в конце обязателен (даже если пустой — напиши «В процессе»).
- Без оценок времени.
- Имя файла: `YYYY-MM-DD-kebab-name.md`, только латиница.

## После создания

```bash
node ./scripts/plans/validate-plans.mjs plans/<имя>.md
```
